在 Linux 上运行 Android 应用

DroidDeck 通过 Waydroid 容器安装并运行安卓应用（APK），提供现代图形界面、应用库、 一键启动，以及可选的 Root 环境（Magisk + Shamiko 隐藏）。

下载最新版 查看源码

图形化安装

仿原生 Android 的安装界面，从应用库一键启动、卸载。

Android 桌面

一键打开全屏安卓桌面，操作体验如同安卓平板。

可选 Root

启动时询问是否启用，自动安装 Magisk 与 Shamiko 隐藏模块。

防格机保护

Root 环境下可拦截格式化分区、清空 /data、向块设备写入等危险操作。

纯本地运行

应用运行在隔离的 Android 容器中，不上传任何数据。

下载

面向 Linux（Debian / Ubuntu / Kali 等）。运行 Android 应用依赖已安装的 Waydroid。

安装

Debian 系 Linux：

sudo apt install ./droiddeck_<版本>_amd64.deb

其它 Linux：下载 tar.gz 解压后运行目录内的 droiddeck。

DroidDeck 是独立开源项目，遵循 GPL-3.0，与 Waydroid、LineageOS、Android、Google 无隶属关系。
